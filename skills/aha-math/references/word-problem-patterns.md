# 应用题视觉模型与低龄解释模板

用于小学题、文字题、用户说“给小朋友讲”“逻辑跳跃”“看不懂”的场景。先选视觉模型，再写 storyboard。

## 低龄解释顺序

```text
具体动作 → 儿童语言 → 口头规则 → 数学语言
```

不要反过来。二年级优先实物动作，不优先公式、字母、括号。

## 差与减法

### 先分清“差”的两种意思（选错模型就会绕）

“差”有两种语义，**先判断题目是哪一种，再选视觉模型**：

| 语义 | 题目长相 | 视觉模型 | 差是什么 |
|------|----------|----------|----------|
| **比较 / 相差** | “两个数的差是…”“甲比乙多多少”“差怎么变” | **两条左对齐长条**（被减数长、减数短） | 被减数条比减数条**露出来的那一截** |
| **拿走 / 还剩** | “有 X，拿走 Y，还剩多少” | 桌上物品 + 拿走的篮子 | 拿走后**剩下的** |

判断口诀：题目在**比两个数**（差/相差/谁比谁多、差怎么变）→ 用对齐双条；题目在**拿走一部分**（还剩多少）→ 用剩下模型。**“两个数的差是 125”属于比较，用对齐双条，不要套成糖果剩下。**

### 模型：对齐双条，差 = 露出的一截（比较/相差类首选）

画两条**左端对齐**的长条：上面被减数（长），下面减数（短）。差 = 减数末端到被减数末端之间**露出的那一截**（用标注线/箭头量出来）。

- **被减数增加** → 上条向右变长 → 露出的一截变长 → **差变大**（增加多少，差就大多少）。
- **减数减少** → 下条变短、末端左移 → 露出的一截**也**变长 → **差变大**（这一步最反直觉，必须强调：减数越小，差反而越大）。
- **两个变化作用在同一截上**，可在一张图上叠加：露出的一截 = 原来的差 + 被减数增加量 + 减数减少量。

配一条会更新的算式跟着画面走：`125 → 125+20 → 145+15 → 160`，让结论是“露出来”一段段加出来的，而不是背规则。

> 这套思路对“差的变化规律”尤其顺：被减数、减数各自的变化都直接映射成长条伸缩，差是同一截的变长，孩子一眼看见“凭什么变大”。

### 模式：少减多少，就多剩多少

适用：

- 减数减少
- 少拿走
- 少扣掉
- 少花掉

视觉：

- 桌上物品 + 拿走的篮子
- 原本拿走一大段
- 后来少拿一小段
- 少拿的那段回到桌上

儿童语言：

```text
这几个没有被拿走，所以还留在桌上。
少拿多少，就多剩多少。
```

数学翻译：

```text
减数减少多少，差就增加多少。
```

禁忌：

```text
减数减少 15，所以差增加 15。
```

这句话不能单独出现，必须先有“少拿走 → 多留下”的动作。

### 模式：多减多少，就少剩多少

适用：

- 减数增加
- 多拿走
- 多扣掉

儿童语言：

```text
多拿走几个，桌上就少剩几个。
```

数学翻译：

```text
减数增加多少，差就减少多少。
```

### 模式：被减数增加，就是先多放

适用：

- 被减数增加
- 原来总数增加

儿童语言：

```text
桌上一开始多放几个，最后也会多剩几个。
```

数学翻译：

```text
被减数增加多少，差就增加多少。
```

## 加减变化题 storyboard 结构

1. 先把“差”换成“剩下多少”。
2. 用小例子演示拿走与剩下。
3. 单独讲最容易误解的变化。
4. 总结口头规则。
5. 翻译回题目术语。
6. 合并计算。

## 年级语言限制

### 二年级

优先用：

```text
桌上有……
拿走……
还剩……
少拿……
多剩……
```

少用或后置：

```text
被减数
减数
差
变化量
等式
括号
```

### 小学高年级

可以使用：

```text
被减数
减数
差
增加
减少
```

但关键误解点仍需用动作或数轴解释。

### 初中以上

可以使用字母：

```text
A - B
A - (B - 15) = A - B + 15
```

但如果用户指出“绕”，必须退回具体动作模型。

## 检查问题

写完 storyboard 后问自己：

- 观众能不能不看公式也明白？
- 最关键的变化有没有被画成动作？
- 有没有一句小朋友能复述的话？
- 有没有把儿童话术翻译回数学？
- 有没有避免把答案直接亮出来？
