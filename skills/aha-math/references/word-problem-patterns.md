# 应用题视觉模型与低龄解释模板

用于小学题、文字题、用户说“给小朋友讲”“逻辑跳跃”“看不懂”的场景。先选视觉模型，再写 storyboard。

## 低龄解释顺序

```text
具体动作 → 儿童语言 → 口头规则 → 数学语言
```

不要反过来。二年级优先实物动作，不优先公式、字母、括号。

## 差与减法

### 模式：少减多少，就多剩多少

适用：

- 减数减少
- 少拿走
- 少扣掉
- 少花掉

视觉：

- 桌上物品 + 拿走的篮子
- 原本拿走一大段
- 后来少拿一小段
- 少拿的那段回到桌上

儿童语言：

```text
这几个没有被拿走，所以还留在桌上。
少拿多少，就多剩多少。
```

数学翻译：

```text
减数减少多少，差就增加多少。
```

禁忌：

```text
减数减少 15，所以差增加 15。
```

这句话不能单独出现，必须先有“少拿走 → 多留下”的动作。

### 模式：多减多少，就少剩多少

适用：

- 减数增加
- 多拿走
- 多扣掉

儿童语言：

```text
多拿走几个，桌上就少剩几个。
```

数学翻译：

```text
减数增加多少，差就减少多少。
```

### 模式：被减数增加，就是先多放

适用：

- 被减数增加
- 原来总数增加

儿童语言：

```text
桌上一开始多放几个，最后也会多剩几个。
```

数学翻译：

```text
被减数增加多少，差就增加多少。
```

## 加减变化题 storyboard 结构

1. 先把“差”换成“剩下多少”。
2. 用小例子演示拿走与剩下。
3. 单独讲最容易误解的变化。
4. 总结口头规则。
5. 翻译回题目术语。
6. 合并计算。

## 年级语言限制

### 二年级

优先用：

```text
桌上有……
拿走……
还剩……
少拿……
多剩……
```

少用或后置：

```text
被减数
减数
差
变化量
等式
括号
```

### 小学高年级

可以使用：

```text
被减数
减数
差
增加
减少
```

但关键误解点仍需用动作或数轴解释。

### 初中以上

可以使用字母：

```text
A - B
A - (B - 15) = A - B + 15
```

但如果用户指出“绕”，必须退回具体动作模型。

## 检查问题

写完 storyboard 后问自己：

- 观众能不能不看公式也明白？
- 最关键的变化有没有被画成动作？
- 有没有一句小朋友能复述的话？
- 有没有把儿童话术翻译回数学？
- 有没有避免把答案直接亮出来？
