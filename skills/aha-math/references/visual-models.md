# 数形结合视觉模型库

把代数关系画成**一个守恒/对应/对称的几何量**，让"数"的逻辑被"形"承载出来。这份是"题型 → 选哪个模型 → 怎么画 → 它让什么逻辑可见 → Manim 怎么落"的速查表。

> 与 `pedagogy-and-storyboard.md §7 推导策略库`（定理/概念的"为什么"路径）互补：§7 偏"证明怎么演"，本表偏"应用题/概念用哪种图"。`templates/mathshapes.py` 提供本表用到的可复用 Mobject。

## 0. 两条总原则

1. **图形即过程（最高原则）。** 解题必须在图形上完成、由动画推出结论，文字只做标注与总结。**禁止纯文字解题、禁止先算出答案再补张图。** 遮住旁白只看画面，关键推理仍要能复述。
2. **先判题型，再选模型；一题一模型。** 不要在一条题里堆两三套比喻（距离 + 糖果 + 公式）。下表"何时用"列就是选择依据。

## 1. 选择速查

| 模型 | 何时用（题型信号） | 它让什么逻辑可见 |
|---|---|---|
| 线段图·整体部分 | "合起来 / 总共 / 缺失的部分" | 部分之和 = 整体 |
| 线段图·比较 | "多/少多少、相差、是几倍" | 长度差 / 长度比 = 差 / 倍 |
| 面积模型 | 乘法分配律、完全平方、平方差、两位数乘、分数乘 | 面积守恒 = 恒等式两边相等 |
| 数轴 | 正负数、相反数、绝对值、不等式解集 | 数→位置；|a|→到原点距离；解集→区间 |
| 坐标系/函数图像 | 一/二次函数、方程(组)、不等式 | 方程的解 = 图像交点；Δ = 交点个数 |
| 天平 | 方程的意义、等式性质、解方程 | 平衡守恒 = 等式性质 |
| 集合/韦恩图 | 分类计数、重叠、容斥 | 重叠被重复计数 → 减交集 |
| 剪拼/重排 | 勾股、三角形/圆/平行四边形面积 | 割补前后面积不变 → 导出公式 |
| 动点/协变 | 正弦曲线、导数=切线斜率、变化率 | 两量同步变化；割线→切线 |
| 实物计数 | 低龄加减、"数得清"的小数量 | 具体物体的合并/移走 |

## 2. 线段图（Singapore bar model）

数形结合里规范最成熟的一套（新加坡建模法 / CPA 的 Pictorial 载体）。**两套模板，一组硬规则。**

### 两套模板

- **整体部分 part-whole**：上方一条"整体"，正下方**等长**一条切成若干"部分"。表示 `部分 + 部分 = 整体`。
- **比较 comparison**：两条**独立、不切分**的实心条上下堆叠、**左端对齐**，长短不同；右端长度差 = 差量。表示两量之差/倍。

### 画法硬规则（务必遵守，部分可 lint）

1. **数量→长度严格成比例**：12 的条必须明显长于 8 的条。这是 bar model 成立的根。
2. **左端对齐**：所有参与比较/求和的条一律左端对齐，差由右端长度差自然呈现。
3. **未知量统一标注**：用 `?`，并优先用**花括号 brace** 框住所指的条段/差量；整体未知时用"花括号 + ?"替代整体条。
4. **分段用线不留空隙**：条内多段之间用分隔线，避免被读成"分离的量"。
5. **等分段严格等长**：乘除/分数/比里各单位段必须等长；余数用专门颜色。
6. **颜色编码语义**：不同部分/不同被比较对象用不同颜色，余数固定一色——颜色承载"这是不同的量"。
7. **先判题型再选模板**："多/少/差/倍" → comparison；"合起来/总共/缺失部分" → part-whole。

### 可见逻辑
把"和÷总份数""差÷份数差"变成**可数的段数**：女生 3 段、男生 1 段，多出 2 段 = 80 人 → 一段 = 40。

### Manim 落法
用 `mathshapes.proportional_bars(...)`（自动左对齐 + 成比例）+ `comparison_diff(...)`（差量描边 + 花括号）/ `part_whole(...)`。分镜按 CPA：(可选实物) → 画条标已知与 `?` → 由图读出运算 → 写算式。

## 3. 面积模型

### 何时用
乘法分配律、完全平方 `(a+b)²`、平方差 `a²−b²`、两位数乘法、分数乘法。

### 怎么画
长方形 `长×宽 = 积`。**只有相同的边才能合并**（分配律的公因数 = 公共边）。
- 分配律 `a(b+c)`：一个高 a 的大长方形，底切成 b、c 两段 → 两个小长方形 `ab`、`ac`，异色填充、标边长。
- 完全平方：边长 `a+b` 的正方形切成 `a²`、`b²`、两块 `ab`。
- 平方差：大正方形挖去小正方形，L 形**剪开重拼**成 `(a+b)×(a−b)` 长方形。

### 可见逻辑
面积守恒 = 恒等式两边相等。`a(b+c)=ab+ac` 是"一个大长方形 = 两个小长方形之和"。

### Manim 落法
`mathshapes.area_partition(a_parts, b_parts, ...)` 生成可标注的网格长方形；平方差用 `Transform` 演"剪开重拼"。

## 4. 数轴

### 何时用
正负数、相反数、绝对值、不等式解集、有理数比较。

### 怎么画
原点 + 单位长度 + 正方向**三要素**；正数右、负数左。
- 相反数：关于原点对称的两点（同色配对）。
- 绝对值：点到原点的**距离**（标距离弧/线段）。
- 不等式解集：一**段区间**，端点开/闭用空心/实心圆，方向用射线。

### 可见逻辑
抽象的数 → 直观位置；`|x|=2` 做成原点两侧对称两点，天然避免漏解。

### Manim 落法
`mathshapes.number_line_marks(...)`（包了 manim `NumberLine`，加点/距离弧/区间）。

---

## 5. 坐标系 / 函数图像

### 何时用
一/二次函数、方程的解、方程组、不等式。

### 怎么画
同一坐标系画图像：方程的解 = 图像与 x 轴**交点**横坐标；方程组的解 = 两图像**交点**；不等式 = 比较两图像高低的 x 范围。二次与 x 轴 0/1/2 个交点对应 Δ 三种情况；可拖参数看图像变化。

### 可见逻辑
"解方程"翻译成"找交点"，函数观点统一方程/不等式/方程组。

### Manim 落法
manim `Axes` + `plot`；交点用 `Dot` + `get_graph_intersection` 思路（手动求交后标点）。

---

## 6. 天平

### 何时用
方程的意义、等式性质、解方程。

### 怎么画
两托盘画等量物体表示等式（平衡 = 相等），未知量用同一图形/字母。演示**两边同时加/减/乘/除同一个量仍平衡**；解方程 = 逐步从两边拿走相同量，直到一边只剩 x。

### 可见逻辑
平衡守恒 = 等式性质。`100+x=250` → 两边同减 100 仍平衡 → `x=150`。把"移项"变成看得见的"保持平衡的操作"。

### Manim 落法
`mathshapes.balance_scale(left, right)`；"两边同时拿走"用同步 `FadeOut`，横梁倾斜/回正用 `Rotate`。

---

## 7. 集合 / 韦恩图

### 何时用
分类计数、重叠问题、容斥（2~3 个集合）。

### 怎么画
2 集合两相交圆；3 集合三圆两两相交（7 区域）。**从最中心 A∩B∩C 往外填**，已知两两交集要先减中心；每集合一色，交集混色。

### 可见逻辑
重叠被重复计数 → 减交集。`|A∪B|=|A|+|B|−|A∩B|` 直接对应"加两圆再减重叠"。

### Manim 落法
`Circle` + `Intersection`（manim 的布尔形状）填色；分区数字用 `Text` 放在各区域质心。

---

## 8. 剪拼 / 重排

### 何时用
勾股定理、三角形/圆/平行四边形面积。

### 怎么画
核心是**割补前后面积不变**。勾股：四个全等直角三角形围成大正方形 + 中空小正方形（赵爽弦图），两种方式算同一面积。圆：偶数等份扇形红蓝交错拼成近似长方形（长≈C/2，宽=r），**份数越多越像**——动画逐步加倍份数。

### 可见逻辑
面积守恒导出公式：`a²+b²=c²`、`圆面积=(C/2)·r=πr²`。份数加倍让"极限逼近"可见。

### Manim 落法
见 `templates/example_pythagoras_proof.py`；圆面积用 `AnnularSector`/`Sector` + `Transform` 演拼合。

---

## 9. 动点 / 协变

### 何时用
正弦曲线生成、导数 = 切线斜率、瞬时变化率。

### 怎么画
- 正弦：单位圆动点带动，过动点作纵坐标线，随弧长沿 x 轴展开描出曲线（同色联动）。
- 导数：固定点 P，动点 Q 沿曲线**滑向** P，割线 PQ 渐变成切线，割线斜率→切线斜率。

### 可见逻辑
协变 = 两量同步变化。Q→P 时割线→切线，使"导数 = 切线斜率"从近似过渡到精确。

### Manim 落法
`ValueTracker` + `always_redraw` 做联动；割线用 `always_redraw(lambda: Line(P, Q.get_center()))`。

---

## 10. 实物计数

### 何时用
低龄加减、数量小到"数得清"。

### 怎么画
数量用 N 个圆/方块排列；加法 = 两组合并；减法 = 移走/消失；倍数 = 一组一组摆。文字只标注，不替代物体。

### Manim 落法
`VGroup(*[Dot()/Square() ...]).arrange()` + `LaggedStart(FadeIn...)`；合并用 `group.animate.next_to(...)`。
